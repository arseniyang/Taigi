# TAIGI — Интернет-магазин одежды

Полнофункциональный e-commerce проект (коммерческий pet-проект), разработанный с нуля для локального бренда одежды. Включает в себя клиентскую часть, личный кабинет и панель администратора.

🌐 **Живой проект (развернут на VDS):** [taigi.ru](https://taigi.ru)

## 🛠 Стек технологий

*   **Backend:** C#, ASP.NET Core MVC (.NET 8/10), Entity Framework Core
*   **База данных:** PostgreSQL (перевод с MS SQL)
*   **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript, jQuery (AJAX)
*   **Архитектура и паттерны:** MVC, Dependency Injection (DI), Service Layer (выделение бизнес-логики), Repository (частично)
*   **Инфраструктура:** Linux (Ubuntu), Nginx (развертывание на VDS)

## ⚙️ Реализованный функционал

### 👤 Для клиентов:
*   **Аутентификация и авторизация:** Кастомная реализация Identity с подтверждением Email и восстановлением пароля.
*   **Каталог:** Просмотр товаров, фильтрация по категориям, регистронезависимый поиск, сортировка и пагинация.
*   **Корзина (AJAX):** Добавление, изменение количества и удаление товаров без перезагрузки страницы. Поддержка разных размеров у одного товара (уникальная привязка `ProductId + Size`).
*   **Промокоды:** Применение и удаление промокодов с динамическим пересчетом итоговой суммы на лету.
*   **Избранное (Wishlist):** Сохранение товаров в избранное.
*   **Оформление заказа:** Выбор способа получения (курьерская доставка / самовывоз), указание контактных данных и времени доставки.
*   **Личный кабинет:** Редактирование профиля, история заказов, управление паролем.

### 🛡 Для администратора:
*   **Управление каталогом:** CRUD-операции для товаров (с загрузкой изображений и drag-and-drop сортировкой), категорий и размеров.
*   **Управление заказами:** Изменение статусов заказов, отслеживание истории изменений.
*   **Управление промокодами:** Создание, активация/деактивация и лимитирование использования промокодов.
*   **Управление остатками:** Контроль количества товаров на складе по каждому размеру.

## 📋 Особенности реализации
*   Реализован кастомный `Middleware` для проверки валидности текущей сессии пользователя.
*   Настроена корректная работа с часовыми поясами при переходе на PostgreSQL (настройка `Npgsql.EnableLegacyTimestampBehavior`).
*   Написаны собственные `js`-скрипты для обработки AJAX-запросов и вывода красивых toast-уведомлений (без сторонних тяжелых библиотек).
*   База данных спроектирована с учетом связей `Один-ко-Многим` и `Многие-ко-Многим`.
